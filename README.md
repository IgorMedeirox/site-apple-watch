# ⌚ Hashwatch

> *Because your wrist deserves a website too.*

Welcome to **Hashwatch** — a pixel-friendly, fan-made product page inspired by the Apple Watch experience. No frameworks, no build steps, no drama. Just pure HTML, CSS, and JavaScript having a good time together.

## ✨ What is this?

Hashwatch is a clone-style landing page for an Apple Watch sport loop band. It lets you:

- 🎨 Switch between **5 gorgeous band colors**: Cypress Green, Winter Blue, Midnight, Starlight, and Light Pink.
- 📏 Pick your **case size**: 41 mm or 45 mm.
- 🖼️ Browse the product with a **live image gallery** that updates as you play around.
- 🍃 Admire the **Carbon Neutral** badge and feel like you’re saving the planet.
- 🛒 Pretend to add things to a bag (the button works, the checkout... not so much).

It’s basically the Apple Store experience, but smaller, cuter, and running entirely in your browser.

---

## 🚀 How to run it

1. Clone this repo (or download it like it’s 2007).
2. Open `index.html` in your favorite browser.
3. Pretend you’re shopping for a $500 band.

That’s it. No `npm install`, no Webpack, no existential crisis.

## 🛠️ Tech stack

| Tech | Role |
|------|------|
| **HTML5** | The bones. |
| **CSS3** | The glow-up. Grid, flexbox, custom fonts, and a little Apple-esque magic. |
| **Vanilla JavaScript** | The brain. Handles color switching, size switching, and image updates. |

No dependencies. No frameworks. Just vibes.
